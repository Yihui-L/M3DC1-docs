M3D-C1 主程序输入参数使用手册

本文是独立发布的 M3D-C1 C1input 参数使用手册，共包含 611 个参数。所有条目属于 &inputnl；逻辑分组按照算例配置流程组织。参数未显式给定时采用表中默认值。

各模块说明给出参数之间的生效条件、覆盖顺序、装置差异及相关模型方程。

【归一化】 / Normalizations

这些量定义 M3D-C1 默认归一化：\(B_{0,\mathrm{norm}}=10^4\,\mathrm{G}\)、\(n_{0,\mathrm{norm}}=10^{14}\,\mathrm{cm}^{-3}\)、\(L_{0,\mathrm{norm}}=100\,\mathrm{cm}\)；多数物理输入/输出使用归一化单位

Normalizations：先把所有物理输入放到同一单位系统

这三个参数在 mesh 和平衡读入之后用于建立全程序的归一化尺度；ion_mass 也参与 Alfvén 速度和时间尺度。除明确标有 SI/cgs 单位并由读取器转换的文件外，C1input 中的演化系数通常应给归一化值。

CASE 第 1 层
\[v_0=\frac{B_0}{\sqrt{4\pi m_i n_0}},\qquad \tau_0=\frac{L_0}{v_0}=\frac{L_0\sqrt{4\pi m_i n_0}}{B_0}.\]
量归一化单位用户含义
压力/能量密度\(p_0=B_0^2/(4\pi)\)压力、电子/离子温度方程中的能量尺度。
温度\(T_0=B_0^2/(4\pi n_0)\)程序温度以能量表示；读取器注明 keV/eV 时会转换。
扩散率\(D_0=L_0^2/\tau_0\)denm 等粒子扩散系数的单位。
电阻率\(\eta_0=4\pi L_0^2/(c^2\tau_0)\)plasma、vacuum 和 conductor 的电阻率统一使用此尺度。
热导率\(\kappa_0=n_0L_0^2/\tau_0\)kappa/kappar 的单位；profile 模式可显式从 SI 转换。

物理 R-Z mesh 和 gfile 量先按各自声明单位读入

【网格】 / Mesh

主程序读取已有 mesh/model 文件；mesh 生成工具的 input 文件格式另见附录

Mesh：从平衡方案到有限元计算域

设置 case 时应先决定装置类型和平衡来源，再设计二维网格、区域标签和环向计算域。程序内部的读取顺序与用户的设计顺序不同：托卡马克直接使用物理 R-Z 网格；仿星器先读取 VMEC 几何并把逻辑网格映射到物理空间，随后才初始化平衡场。

CASE 设置链条
用户设计顺序装置与平衡模式 → 物理计算域 → 二维 mesh/model → boundary/zone → 环向域 → 分辨率检查
程序运行顺序读取几何设置 → 装载二维 mesh/model → 建立物理坐标 → 生成环向三维域 → 投影平衡和初始场
托卡马克

mesh 坐标就是物理柱坐标 (R,Z)

  1. 先选平衡入口。直接使用 gfile 时选择 iread_eqdsk=1, igs=0；需要 M3D-C1 求解 GS 时使用 gfile 作为初值，或完全由解析/输入剖面建立初值。此选择决定 mesh 需要覆盖的物理区域和可用的外部数据范围。
  2. 在物理 R-Z 平面生成网格。标准设置为 igeometry=0、iread_vmec=0。mesh_filename 中每个节点的坐标就是实际 R 和 Z；读取 gfile 不会移动节点，也不会把圆形 mesh 变成等离子体形状。
  3. 按希望演化的区域确定外边界。只算等离子体可把域截断在目标边界；要计算等离子体外真空、第一壁或电阻壁，原始 mesh/model 必须已经包含这些实体。扩大 plasma zone 本身不会把固定边界平衡变成自由边界平衡。
  4. 给现有单元赋予物理标签。imulti_region=0 会把全部单元强制视为 plasma；imulti_region=1 时用 zone_type 标记 plasma/conductor/vacuum，用 boundary_type 标记 first wall/domain boundary。标签只分类，不改变几何。
  5. 再选择二维或三维环向域。二维及 complex 线性计算使用 nplanes=1；真实三维计算使用 nplanes>1。托卡马克通常取 nperiods=1, ifull_torus=1；只有明确利用环向周期性时才截取扇区。
  6. 最后检查平衡与网格的相容性。gfile 数据按 R-Z 坐标插值到所有 mesh 单元，并不限于 plasma zone。用户需保证节点位于所需 gfile 数据框内，并保证 LCFS、真空、壁和计算域外边界在物理上合理；程序不做这项一致性认证。
设置层次主要参数托卡马克用法
坐标与几何igeometry, iread_vmec, xcenter/zcenter, bloat_*, nzer_*常规物理 R-Z mesh 取 igeometry=0, iread_vmec=0；VMEC 映射、bloat 和 Zernike 阶数均不参与。xzero/zzero 也不能用于平移外部 mesh。
二维文件mesh_filename, mesh_model, model_infomesh 保存节点和单元，model 保存边界/zone 拓扑；二者编号必须一致。model_info 仅专用 CAD 编译路径使用。
区域imulti_region, boundary_type(i), zone_type(i)单区时自动全 plasma；多区时必须逐编号给出有效类型。导体 zone 的材料参数另在 Resistive Wall 组中用 eta_zone/etaRZ_zone 等设置。
环向离散nplanes, nperiods, ifull_torus, iread_planes, toroidal_pack_*未读 plane_positions 时默认均匀分布；packing 只调整平面角度，不改变二维截面。3D+PETSc 当前要求 MPI rank 数等于 nplanes。
数值后端imatassemble, is1_agg_blks, is1_agg_scp, ipartitioned仅影响矩阵装配、聚合或保留的兼容选项，不改变几何、zone 或平衡映射。
仿星器

二维 mesh 是逻辑圆盘，VMEC 决定物理几何

  1. 先选固定边界或外场/自由边界初始化。固定边界通常为 itaylor=40，直接使用 wout 中的几何、磁场和压力；外场/自由边界路径通常为 itaylor=41，磁场由外场/总场文件初始化。两种路径都应先决定物理计算域是否只到 VMEC 边界，还是需要向外 bloat。
  2. 生成二维逻辑圆盘 mesh。常用 igeometry=1, iread_vmec=1。mesh 文件的 x、z 不是最终物理 R、Z，而用于构造 \(\rho=\sqrt{(x-x_{\mathrm{center}})^2+(z-z_{\mathrm{center}})^2}\) 和逻辑极角；因此 xcenter/zcenter 必须与生成圆盘时使用的圆心一致。
  3. 用 VMEC 几何完成坐标映射。vmec_filename 提供 R/Z 傅里叶系数和场周期。逻辑 (rho,theta,phi) 被映射为物理 (R,Z,phi)；逻辑圆形单元在物理空间通常成为非圆、随环向扭转的棱柱单元。
  4. 决定逻辑外边界对应哪里。无 bloat 时，逻辑 rho=1 通常映射到 VMEC 最外磁面。bloat_factor 或 bloat_distance 可把计算边界向外扩展；距离参数优先。外扩区域不会自动获得 vacuum、first wall 或 conductor 的标签。
  5. 谨慎设计多区域。boundary_type/zone_type 标记的是映射前逻辑 mesh 中已经存在的边和 zone。程序只验证类型值和编号，不根据 wout 的 LCFS、mgrid 范围或真实壁面检查标签位置。语法合法的 conductor zone 仍可能映射到真实等离子体内部。
  6. 按场周期生成三维域。nperiods 定义环面周期分割；ifull_torus=0 只计算一个相应扇区，此时 VMEC nfp 必须能被 nperiods 整除。nplanes 是所选域内的环向平面数，应解析几何和磁场中的最高相关环向模。
  7. 映射完成后再写入平衡场。固定边界路径把 wout 的 B、压力等投影到物理有限元域；外场路径写入外部/总磁场。mesh 的 zone 标签不会选择 VMEC 数据的读取范围，也不会替代平衡边界。
目标推荐组合用户需要确认
固定边界 VMECitaylor=40, igeometry=1, iread_vmec=1, bloat_factor=0, bloat_distance=0逻辑外边界与 wout 最外磁面对应；通常使用单一 plasma zone。程序显式要求 bloat_factor=0，同时应关闭距离外扩。
外扩计算域igeometry=1, iread_vmec=1，并选择一种 bloat_*外扩只改变几何映射；真空、壁和材料区域仍须在 mesh/model 与 zone 参数中显式设计。
周期扇区ifull_torus=0, 合理的 nperiods 和 nplanes需满足 \(n_{\mathrm{fp}}\bmod n_{\mathrm{periods}}=0\)，且所有自定义 plane_positions 均位于当前扇区角度范围内。
几何阶数调节nzer_manual 优先；否则使用非负 nzer_factor只在 VMEC 到 Zernike 几何表示的精度测试中调整；默认值通常更稳妥。
共同原则：mesh 是有限元几何和拓扑的地基，平衡数据负责定义初始物理场。区域标签、坐标映射和平衡边界是三件独立的事；M3D-C1 会按输入执行，但不会证明三者在物理上彼此一致。

【平衡与初始条件】 / Equilibrium

选择/缩放初始平衡、外场、RMP、stellarator 场、basicj 模型以及初始扰动

Equilibrium：把输入数据和网格变成可演化的 MHD 基态

本模块承接 Input 与 Mesh：Input 已决定平衡数据从哪里来，Mesh 已决定计算域、边界和 zone；Equilibrium 再选择直接投影、重新求解或解析初始化，建立基态磁场与热力学场，并叠加外场和初始扰动。之后 Model Options、Transport 与 Boundary Conditions 才决定这些场怎样演化。

模块递进
前置模块提供Input：gfile / wout / profile / restart 的读取入口与覆盖顺序
Mesh：物理或逻辑坐标、计算域、zone 与 boundary 标签
本模块输出平衡场 0 层：\(\psi_0,F_0,p_0,n_0,\mathbf V_0\)
扰动场 1 层与可选外场：\(\delta\psi,\delta F,\mathbf B_{ext}\)
Input 选择数据源→Mesh 建立计算域与 zone→读入或求解基态→外场分解→初始扰动与符号约定→Model/Transport 时间演化
固定边界/自由边界不是一个孤立开关：必须同时看平衡来源、ifixedb、mesh 外边界、PF 线圈、imulti_region/zone_type 和 GS 是否启用。无论哪种 GS 设置，有限元计算域的最外边界始终存在；“自由”指等离子体 LCFS 可在更大的固定计算域内由电流与线圈场共同决定。
托卡马克

从 gfile / GS 选择开始，再决定 LCFS 外是否进入计算域

  1. 先由 Input 选择基态来源。iread_eqdsk=1,igs=0 直接投影 gfile；igs>0 才重新求解 GS；三个读取入口均为 0 时可用 itaylor=1 从解析初值和剖面求 GS，或选择其它测试平衡。
  2. 再由 Mesh 决定物理计算域。托卡马克 mesh 节点就是 R-Z 坐标。若只覆盖 gfile LCFS 内部，模型天然接近固定等离子体边界；若覆盖 LCFS 外真空和导体，则必须用 imulti_region=1 及 zone_type 给这些单元明确物理意义。
  3. 选择 GS 的外边界方式。ifixedb>=1 在计算域外边界强制 \(\psi=0\)；ifixedb=0 先建立等离子体电流和 PF 线圈真空场，再把该场值作为 GS 外边界，LCFS 在域内重新寻找。
  4. 建立等离子体源与真空场。GS 的 \(p'(\psi)\) 与 \(FF'(\psi)\) 源只放在 plasma zone 且被判为 plasma magnetic region 的位置；外部 vacuum/conductor zone 仍参与磁场椭圆方程，但不承载等离子体 GS 源。
  5. 最后叠加独立磁场。RMP、error field、TF/PF 线圈误差在基态之后投影，不会再次求解 GS，也不会重写 gfile/GS 压力或电流剖面。extsubtract/icsubtract 决定这些场并入基态还是单独保存。
  6. 进入时间演化。Model Options 决定是否扣除平衡场、是否加入 bootstrap closure；Transport 根据 zone 选择 plasma、vacuum 或 conductor 的电阻率和输运系数。

直接投影与 zone

gfile 的 \(\psi,p,F\) 会在读取路径中插值到 mesh 单元，不只写 plasma zone。zone 标签不会裁剪输入数据；它主要决定随后哪些方程、材料系数和源项生效。

GS 求解与 zone

GS 矩阵覆盖整个计算域，但 plasma 电流源只在 ZONE_PLASMA 内。非 plasma zone 的压力取边缘值、环向真空场取 bzero*rzero；vacuum 与 conductor 的差异主要在后续电阻率和壁电流演化。

仿星器

区分固定边界 VMEC 投影与三维 total/external-field 初始化

  1. 首先由 Input 关闭托卡马克入口。iread_eqdsk=iread_dskbal=iread_jsolver=0；否则程序会优先执行轴对称初始化，不进入 itaylor=40/41。
  2. 由 Mesh 建立逻辑域并映射。通常 igeometry=1,iread_vmec=1；逻辑 \((\rho,\theta,\phi)\) mesh 先映射到物理 R-Z-phi，zone 与 boundary 标签随映射带入，但不会由 wout 或场文件自动重分类。
  3. 选择固定边界。itaylor=40 读取 wout 的几何、磁场和压力并进行投影；M3D-C1 不求解 VMEC。此模式要求 bloat_factor=0，同时应设置 bloat_distance=0，使外边界对应 VMEC 最外磁面。
  4. 或选择三维外场初始化。itaylor=41 要求 iread_ext_field!=0，从 total field 或 total/external 组合建立磁场。该路径不求解 VMEC 自由边界方程，也不根据第一壁位置重新求解 LCFS。
  5. 检查计算域物理意义。bloat 只扩展几何映射；扩展区是 plasma、vacuum 还是 conductor 仍完全由 zone_type 决定。程序允许但不会识别“导体 zone 实际落在 wout plasma 内”等物理冲突。
  6. 再进入演化模型。RMP/外场分解、bootstrap、transport 和壁电阻依次作用；这些模型不会回头改变 VMEC 映射或重求平衡边界。

plasma 与外部区

itaylor=40 的 wout 平衡定义到最外磁面。若通过 bloat 或多区域逻辑 mesh 建立外区，程序不会依据 wout 判断该区属于真空、导体壁或等离子体；必须在 Mesh 阶段定义 zone，并在 Transport/Boundary 模块设置材料参数。

itaylor=41 的自由边界含义

itaylor=41 读取三维 total/external field 并初始化 MHD 场。该模式允许 LCFS 在后续 MHD 演化中变化，但不执行基于 mgrid 背景场求解 LCFS 的 VMEC 自由边界平衡迭代。

固定边界 VMEC 的几何约束：初始化显式检查 bloat_factor==0。为保证 mesh 外边界与 wout 最外磁面严格对应，还应显式设置 bloat_distance=0。

Grad-Shafranov Solver：托卡马克轴对称基态求解

本模块只处理托卡马克的轴对称 Grad-Shafranov 平衡。它承接 Input 选定的 gfile/剖面与 Mesh/Equilibrium 建立的物理 R-Z 计算域，在固定的有限元外边界内迭代求解磁通、寻找磁轴与 LCFS，再把压力、环向场、密度和转动投影为可演化的 MHD 基态。

第三步：建立进入 GS 方程的剖面

求解方程可写为

\[\Delta^{*}\psi + R^{2}\frac{dp}{d\psi} + F\frac{dF}{d\psi}=0,\qquad F(\psi)=R B_{\phi}.\]

剖面查询坐标不是 mesh 的径向坐标，而是每轮由磁轴与 LCFS 更新的磁通坐标：

\[s_{\psi}=\frac{\psi-\psi_{\mathrm{axis}}}{\psi_{\mathrm{LCFS}}-\psi_{\mathrm{axis}}}\,\mathtt{psifrac}.\]

第四步：Picard 迭代、约束与收敛

  1. 固定矩阵。程序先在全部单元组装 GS 椭圆算子，并在计算域外边界施加 Dirichlet 条件；USE3D 编译可用 eta_gs 抑制 psi 的非轴对称变化。
  2. 解线性化磁通。当前 p' 与 FF' 形成右端项，求得新的 psi。只有 iread_eqdsk=1 的第一轮跳过这次线性求解，以保留 gfile 初值。
  3. 松弛更新。从第二个已求解轮次起按 \(\psi\leftarrow\mathtt{th\_gs}\,\psi_{solve}+(1-\mathtt{th\_gs})\,\psi_{old}\) 混合。
  4. 重找磁轴和 LCFS。新的轴与边界磁通改变 \(s_\psi\)，程序据此重新评价 p'、FF' 与磁区。
  5. 施加解析约束。非完整剖面约束时，q0、djdpsi、tcuro 分别通过 gamma2、gamma3、gamma4 调整 FF' 基函数；nv1equ=1 会把这三个 gamma 全部关掉。
  6. 检查收敛。第二轮后若解变化误差小于 tol_gs 就提前退出，否则最多执行 igs 轮。

【模型选项】 / Model Options

控制求解的 MHD 方程组、线性/非线性、two-fluid、bootstrap、runaway、温度/压力模型等

Model Options：从守恒定律到实际推进变量

本组承接 Mesh、Input 与 Equilibrium 已建立的几何、区域和初始场，决定时间推进所包含的流体、电磁和热力学自由度。M3D-C1 不把总能量密度作为单独有限元未知量；程序通过总压强、电子压强或电子/离子温度方程推进内能，并与动量方程、Faraday 定律及广义 Ohm 定律共同保持所选模型的能量收支。

CASE 物理核心
能量方程的位置：压力方程和温度方程就是程序的内能方程。因而，参数表中未出现名为“total energy”的演化变量，并不表示能量演化被省略。

本节公式采用便于识别物理量的有量纲 SI 形式；进入程序后，各项按 Normalizations 中定义的 \(B_0,n_0,L_0\) 转为无量纲形式。

理想 MHD 的三条守恒律

忽略扩散、粘性、电阻率、外源和 two-fluid 修正时，M3D-C1 所用模型以理想可压缩 MHD 为骨架。采用总能量密度

\[\mathcal E=\frac{1}{2}\rho v^2+\frac{p}{\Gamma-1}+\frac{B^2}{2\mu_0},\]

质量、动量和总能量的守恒形式可写为

\[\frac{\partial\rho}{\partial t}+\nabla\!\cdot(\rho\mathbf v)=0,\]
\[\begin{aligned} \frac{\partial(\rho\mathbf v)}{\partial t}+\nabla\!\cdot(\rho\mathbf v\mathbf v+p\mathbf I) &\\ +\nabla\!\cdot\!\left(\frac{B^2}{2\mu_0}\mathbf I-\frac{\mathbf B\mathbf B}{\mu_0}\right)&=0, \end{aligned}\]
\[\begin{aligned} \frac{\partial\mathcal E}{\partial t}+\nabla\!\cdot\mathbf F_{\mathcal E}&=0,\\ \mathbf F_{\mathcal E}&=\left(\mathcal E+p+\frac{B^2}{2\mu_0}\right)\mathbf v-\frac{(\mathbf v\!\cdot\mathbf B)\mathbf B}{\mu_0}. \end{aligned}\]

以上总能量式用于说明守恒结构。实际 extended-MHD 推进将其拆为动能、磁能与内能收支，并显式加入粒子扩散和源项、粘性应力、热流、电阻耗散、辐射及外部驱动。

M3D-C1 实际使用的流体方程

\[\frac{\partial n_i}{\partial t}+\nabla\!\cdot(n_i\mathbf v)=\nabla\!\cdot(D\nabla n_i)+\sigma_i,\]
\[\begin{aligned} D_t&\equiv\frac{\partial}{\partial t}+\mathbf v\!\cdot\nabla,\\ \rho D_t\mathbf v&=\mathbf J\!\times\mathbf B-\nabla p-\nabla\!\cdot\boldsymbol\Pi-\varpi\mathbf v. \end{aligned}\]

单主离子模型中，\(n_e=Z_i n_i\)、\(\rho=m_i n_i\)、\(\varpi=m_i\sigma_i\)。杂质模型启用后，准中性关系、质量密度和粒子源按所有电荷态求和。

内能、压力与温度方程

最完整的双温度表示分别推进电子温度和离子温度。温度以能量单位表示，\(p_e=n_eT_e\)、\(p_i=n_iT_i\)、\(p=p_e+p_i\)：

\[\begin{aligned} n_e\!\left[D_tT_e+(\Gamma-1)T_e\nabla\!\cdot\mathbf v\right]+\sigma_eT_e &=(\Gamma-1)\!\left[\eta\mathbf J\!\cdot(\mathbf J-\mathbf J_x)-\nabla\!\cdot\mathbf q_e\right.\\ &\hspace{4.2em}\left.+Q_e-\boldsymbol\Pi_e\!:\nabla\mathbf v\right]. \end{aligned}\]
\[\begin{aligned} n_i\!\left[D_tT_i+(\Gamma-1)T_i\nabla\!\cdot\mathbf v\right]+\sigma_iT_i &=(\Gamma-1)\!\left[-\nabla\!\cdot\mathbf q_i+Q_i\right.\\ &\hspace{4.2em}\left.-\boldsymbol\Pi_i\!:\nabla\mathbf v+\frac{1}{2}\varpi v^2\right]. \end{aligned}\]

压力表示由连续性方程和 \(p_s=n_sT_s\) 得到；无源、无耗散时退化为 \(D_t p+\Gamma p\nabla\!\cdot\mathbf v=0\)。启用 two-fluid 后，电子热方程还包含由电子相对离子漂移产生的电子压强平流及相应功项。

从内能守恒推导压力/温度方程

对任一流体组分 \(s\)，以内能密度 \(\varepsilon_s=p_s/(\Gamma-1)\) 写第一定律：

\[\frac{\partial\varepsilon_s}{\partial t}+\nabla\!\cdot(\varepsilon_s\mathbf v)=-p_s\nabla\!\cdot\mathbf v-\nabla\!\cdot\mathbf q_s+H_s.\]

将 \(p_s=n_sT_s\) 和连续性方程代入，可得到温度形式

\[n_s\left[D_tT_s+(\Gamma-1)T_s\nabla\!\cdot\mathbf v\right]=(\Gamma-1)\left(-\nabla\!\cdot\mathbf q_s+H_s\right),\]

或等价的压力形式

\[D_tp_s+\Gamma p_s\nabla\!\cdot\mathbf v=(\Gamma-1)\left(-\nabla\!\cdot\mathbf q_s+H_s\right).\]

粒子源、粒子扩散和 two-fluid 漂移存在时，连续性方程会在这两种变量变换中产生相应附加项；这正是 iadiabat、电子压强平流和源项修正的来源。

总能量守恒可由三类方程直接相加验证。动量方程点乘 \(\mathbf v\) 给出动能收支，Faraday 与 Ampère 定律给出 Poynting 定理

\[\frac{\partial}{\partial t}\left(\frac{B^2}{2\mu_0}\right)+\nabla\!\cdot\left(\frac{\mathbf E\times\mathbf B}{\mu_0}\right)=-\mathbf J\!\cdot\mathbf E.\]

理想项 \(\mathbf E=-\mathbf v\times\mathbf B\) 使磁能中的 \(-\mathbf J\!\cdot\mathbf E\) 与动能中的 \(\mathbf v\!\cdot(\mathbf J\times\mathbf B)\) 抵消；压强功在动能和内能之间抵消。当 \(\mathbf J_x=0\) 时，电阻项从磁能移除 \(\eta J^2\)，并在 iohmic_heating=1 时作为电子或总热方程中的正加热项返回；非零 \(\mathbf J_x\) 表示与外部电流驱动的能量交换。因此无需直接推进 \(\mathcal E\) 也能形成完整能量账目。

约化麦克斯韦方程组与广义 Ohm 定律

\[\begin{aligned} \frac{\partial\mathbf B}{\partial t}&=-\nabla\times\mathbf E, & \mu_0\mathbf J&=\nabla\times\mathbf B,\\ \nabla\!\cdot\mathbf B&=0.&& \end{aligned}\]
\[\begin{aligned} \mathbf E={}&-\mathbf v\times\mathbf B+\eta(\mathbf J-\mathbf J_x)\\ &+\frac{1}{n_e e}\left(\mathbf J\times\mathbf B-\nabla p_e\right). \end{aligned}\]

这是低频 MHD 近似：不推进电磁波，不保留位移电流；电荷分离由准中性条件消去，电子动量方程化为广义 Ohm 定律。归一化方程使用 db/db_fac 给定 Hall 与电子压强项的离子皮肤深度系数。

该 Ohm 定律来自忽略电子惯性后的电子动量平衡：

\[0=-n_e e\left(\mathbf E+\mathbf v_e\times\mathbf B\right)-\nabla p_e-\nabla\!\cdot\boldsymbol\Pi_e+\mathbf R_e+\mathbf F_e.\]

利用 \(\mathbf J=n_e e(\mathbf v-\mathbf v_e)\) 消去电子速度，碰撞摩擦 \(\mathbf R_e\) 形成电阻项，便得到 \(\mathbf J\times\mathbf B/(n_e e)\) 的 Hall 项和 \(-\nabla p_e/(n_e e)\) 的电子压强项。粘性、热力和外力模型启用时，相应项继续保留在广义 Ohm 定律中。

程序不直接以三个笛卡尔分量存储 \(\mathbf B\) 和 \(\mathbf v\)，而在环向坐标 \(\varphi\) 中使用势函数表示：

\[\begin{aligned} \mathbf A&=R^2\nabla\varphi\times\nabla f+\psi\nabla\varphi,\\ \mathbf B&=\nabla\times\mathbf A=\nabla\psi\times\nabla\varphi+F\nabla\varphi-\nabla_p f',\\ \mathbf v&=R^2\nabla U\times\nabla\varphi+R^2\omega\nabla\varphi+R^{-2}\nabla_p\chi. \end{aligned}\]

其中 \(\nabla_p=\nabla-\nabla\varphi\,\partial_\varphi\)、\(f'=\partial_\varphi f\)、\(F=R^2\nabla_p^2f\)。因此 \(\nabla\!\cdot\mathbf B=0\) 由磁场表示满足，而不是作为额外标量演化方程求解；numvar 选择上述势函数中参与时间推进的子集。

从矢量 MHD 方程到约化标量方程

速度表示把流动分成极向旋转、环向流动和可压缩三部分。对动量残差 \(\mathbf M=0\) 分别施加下列投影算子，得到三个标量方程：

\[\begin{aligned} \mathcal P_U(\mathbf M)&=-\nabla\varphi\!\cdot\nabla\times(R^2\mathbf M),\\ \mathcal P_V(\mathbf M)&=R^2\nabla\varphi\!\cdot\mathbf M,\\ \mathcal P_\chi(\mathbf M)&=\nabla_p\!\cdot(R^{-2}\mathbf M). \end{aligned}\]

三者依次是极向涡量方程、环向动量方程和压缩方程，对应 \(U\)、环向速度变量 \(V/\omega\) 与 \(\chi\)。电磁部分采用相同思路：jadv=0 时取矢势感应方程的环向分量得到 \(\psi\) 方程；jadv=1 时对 Faraday 定律取旋度并作环向投影，改为推进环向电流；Faraday 定律的环向磁场分量给出 \(F\) 方程。

numvar保留的基本标量场约化含义
1\(U,\psi\)二场模型，仅保留极向涡量与极向磁通的核心耦合。
2\(U,\psi,V,F\)四场约化 MHD，增加环向动量和环向磁场响应。
3\(U,\psi,V,F,\chi\) 与热力学槽六场可压缩 MHD，恢复压缩流动和动态内能；idens、ipres 可再增加独立密度和第二热力学未知量。

有限元离散再以测试函数 \(\mu\) 对每个标量残差 \(\mathcal R_k\) 建立 Galerkin 弱式 \(\int_\Omega\mu\mathcal R_k\,dV=0\)，并通过分部积分降低场变量所需导数阶数。由此，程序中看到的是 \(U,\psi,V,F,\chi,p_e,n,p\) 等弱式矩阵项，而不是直接逐分量离散原始矢量守恒方程。

【时间推进】 / Time Step

时间积分、分裂/非分裂推进、可变时间步、矩阵/预条件器重算及线性增长率停止条件

Time Step：把已选物理方程变成逐步线性系统

这一步位于模型、输运、边界之后。先选 split/unsplit 和积分器，再决定矩阵与预条件器复用，最后才启用基于动能/KSP 迭代数的自适应时间步。

CASE 推进层
\[\frac{q^{n+1}-q^n}{\Delta t}=F\!\left(q^n+\theta(q^{n+1}-q^n)\right),\qquad \theta=\mathtt{thimp}.\]
阶段参数使用逻辑
积分公式integrator, thimp, dt, ddt0 为 theta 法（0.5 为 CN）；1 为 BDF2 并强制 theta=1。ddt 是每步时间步增量。
方程拆分isplitstep, imp_mod, caramana_fac, ipressplitsplit 按磁场、速度、密度、热力学分块；unsplit 组装整体系统并强制 imp_mod=0。
系数更新iteratephi, irecalc_eta, iconst_eta决定在分块之间是否用新密度/温度重算输运及磁场。
矩阵复用nskip, pskip, iskippc分别控制矩阵和不同层次预条件器的更新/复用；系数变化快时应缩短周期。
可变步长dtkecrit, dtmin/max, dtfrac, ksp_min/warn/max, max_repeat只有 dtkecrit>0 才进入此控制；步长每次乘/除 \(1+dtfrac\)，并限制在 min/max。3D 迭代超限可重做当前步。
停止条件gamma_gr_stop, nt_gamma_gr, gamma_gr_stop_std线性计算用动能增长率滑动标准差判断收敛，写出时间片后停止。
托卡马克

2D/complex 与真实 3D 的代价控制不同

复杂线性响应可用 itime_independent=1 与 frequency；真实 3D 才使用全局最大 KSP 迭代数触发重复/调步。

【网格自适应】 / Mesh Adaptation

SCOREC/SPR 网格自适应控制；部分参数仅在启用对应库/流程时有效

Mesh Adaptation 在计算中的作用

网格自适应根据预设磁通结构或当前离散误差重新分配局部空间分辨率。它会细化/粗化网格、转移已有场、重建有限元矩阵并重新进行并行划分，但不会重新判定 LCFS、第一壁或 zone 类型。

使用补充
构造目标尺寸场→SCOREC/PUMI 细化与粗化→高阶场转移→重建网格和矩阵→继续时间推进

SCOREC 与 SPR

SCOREC 是 RPI 的 Scientific Computation Research Center；在程序中也指该中心开发的 PUMI/APF、MeshAdapt 和并行负载均衡软件栈，负责修改网格。

SPR 是 Superconvergent Patch Recovery（超收敛斑片恢复）误差恢复算法，用于从解场恢复梯度并提出目标网格尺寸。

边界与区域保持不变

适配沿用原 mesh/model 的几何分类和 zone 标签。iadapt_snap=1 时，新边界节点会尽量贴回已有模型边界；它不会生成新的第一壁、真空区或导体壁，也不会把 LCFS 自动变成网格分区面。

适配路径尺寸依据主要用途性质
adapt_by_psi平衡磁通 psi、q 面、线圈和 pellet 路径计算开始前预布置 LCFS/SOL 等区域的网格磁通面法向/切向可采用不同尺寸，属于各向异性适配
adapt_by_error速度势 U 与磁通 psi 的边跳跃和方程残差在时间推进中根据离散误差动态调整合成节点误差后生成各向同性尺寸场
adapt_by_spr当前 psi 场的 SPR 恢复梯度多步演化中跟踪解的局部细尺度由 isprntime 控制调用周期

iadapt 的模式选择

0
关闭适配
1
初始化时按磁通适配
2
推进中按误差适配
3
初始化按磁通，推进中按误差
4
初始化及推进中均可按误差适配

动态触发条件

iadapt_ntime>0 时每隔指定步数检查；非线性计算且该值为零时每步检查；线性计算还可由 adapt_ke 的动能阈值触发。检查后只有估计误差超过 adapt_target_error 才实际换网格。

ispradapt=1 时使用独立 SPR 路径，并抑制推进中的普通 error-estimator 路径。

三维 SPR 的处理

多环向平面情况下，程序分别计算各平面的尺寸要求，对对应节点取最小值，再适配二维母网格并恢复全部环向平面。因此它改变极向网格拓扑，但不改变 nplanes 或环向平面间距。

适配后的场

SCOREC/PUMI 使用 M3D-C1 的高阶场转移把需要保留的解投影到新网格，随后更新节点所有权、单元几何和求解矩阵。初始磁通适配的非重启算例还会重新调用初始条件，把平衡再次投影到新网格。

使用限制：按磁通适配还需要工作目录中的 sizefieldParam（13 或 14 个数），并依赖 USESCOREC 编译选项。adapt_factor 和 adapt_smooth 虽可读入，但不参与活动计算。普通 error-estimator 尚未提供完整的多平面尺寸场处理；多平面计算应使用 SPR 路径。

【PRAD 简单辐射模型】 / PRAD Options

简单单杂质辐射模型

PRAD：不演化电荷态的单杂质瞬时辐射模型

PRAD 在现有电子密度和温度上计算单一杂质的辐射冷却，不增加每个电荷态的连续方程。它需要非线性压力/温度方程，且 Model Options 中 irad_heating=1 才把损失写入热方程。

简单辐射
\[P_{rad}=n_e n_Z L_Z(T_e),\qquad n_Z=\mathtt{prad\_fz}\,n_e\ \text{或由 profile\_nz 给定}.\]
参数用法
iprad1 开启；0 不计算 PRAD。
prad_z选择辐射表的原子序数；当前活动表面向 C=6、Ar=18、Fe=26，其它值只给警告，不能视为有可靠数据。
prad_fz未读文件时的杂质总密度/电子密度比例。
iread_prad1 读 profile_nz：第一列 \(\psi_N\)，第二列为 \(10^{20}\,m^{-3}\) 杂质密度，并覆盖比例模型。
托卡马克

文件剖面按归一化磁通使用

PRAD 本身只读局部 \(n_e,T_e,n_Z\)，但 profile_nz 的空间映射依赖轴对称磁通坐标。

仿星器

局部比例模型可工作，普通 psi 剖面不具有明确三维映射

prad_fz 的局部比例公式不区分装置；若要给三维仿星器杂质分布，应确认当前版本的 profile 映射，不要默认它等于 VMEC 的 s。

【KPRAD 辐射/杂质模型】 / KPRAD Options

KPRAD 杂质电离/复合/辐射与中性粒子演化控制

KPRAD：逐电荷态演化、准中性和辐射能量耦合

KPRAD 在主离子 MHD 上增加一个杂质元素的中性态与所有离化态密度；电离/复合在每个 MHD 步内自适应子循环，随后更新电子密度、质量密度和热损失。

多电荷态杂质
\[\partial_t n_Z^{(j)}+\nabla\!\cdot(n_Z^{(j)}\mathbf v)=\nabla\!\cdot(D_j\nabla n_Z^{(j)})+\sigma_Z^{(j)},\qquad n_e=Z_i n_i+\sum_{j=1}^{Z}j\,n_Z^{(j)}.\]
步骤参数作用
原子数据ikprad, kprad_z, adas_adf111 用内置拟合（支持 Z=1,2,4,5,6,10,18）；-1 仅在 USEADAS 编译下读 ADF11 路径。
初始中性杂质kprad_nz, kprad_fz, iread_lp_source初始中性密度为常数项加电子密度比例；Lagrangian-particle 源读取 cloud.txt，属于专用 pellet 工作流。
空间输运ikprad_evolve_neutrals, kprad_n0_denm_fac0 中性不对流/扩散；1 对流并扩散；2 只扩散。离化态随主流体并使用密度扩散。
低值处理kprad_nemin, kprad_temin, ikprad_min_option选项 1 使用默认全反应；2 低值处禁电离/辐射但允许受限复合；3 在子循环中低于阈值时关闭电离、复合和辐射。
子步ikprad_max_dt, kprad_max_dt选项 1 令上限为 \(dt/(Z+1)\)，显式正值可进一步限制；算法在电子密度变化超过 20% 时回退减半，小于 2% 时增大子步。
内部热反馈ikprad_evolve_internal1 在每个 KPRAD 子步内更新局部 \(n_e,T_e\) 和反应率；0 在整 MHD 步内冻结输入反应率。
\[Q_e\supset-\left(P_{line}+P_{brem}+P_{ion}+P_{rec,kin}\right).\]
托卡马克

电荷态方程作用于 plasma zone 并随 MHD 流演化

可与 pellet/杂质注入联合使用。KPRAD 不重新求 GS，也不会覆盖初始主离子剖面；它在时间推进中通过准中性和质量项反馈。

仿星器

同一局部反应与三维输运方程作用于映射域

原子率只依赖局部 \(n_e,T_e\)，装置无关；中性/杂质源的空间位置和逻辑/物理坐标仍需与 VMEC 映射及 zone 对齐。

能量含义：程序计算复合释放的动能与势能，但热方程只扣除 kinetic recombination 项；势能释放不再次从电子流体动能中扣除。
